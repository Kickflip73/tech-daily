### 2. 算法理论年度地震：OpenAI 攻克矩阵乘法指数 + Google Cogentic 算法突破

**这不是 GitHub Trending 上的项目，但今天是理论 CS 多年来最重要的一天，必须置顶讲。**

### 🔴 OpenAI math：矩阵乘法指数 ω = 9/4（HN 1,019 分，568 评论）

> **论文**：https://github.com/openai/math/blob/main/preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026/paper.pdf

**这是什么：** OpenAI 数学团队（openai/math 仓库）发布论文：**矩阵乘法指数 ω 的上界被改进到 9/4 = 2.25**。矩阵乘法复杂度是计算理论的最核心问题之一——Strassen（1969，ω<3）以来人类追了近 60 年，此前最好结果是 2.371879...（Alman-Williams / Duan-Wu 系列渐近挤压）。**ω=2.25 是一次跳跃式改进**，距理论下界 2 又近一步。

**为什么所有开发者都该关心：** 矩阵乘法是深度学习的计算基石。ω 的改进虽是渐近理论（超大矩阵才体现），但历史上 laser method/tensor rank 的每次突破都会缓慢渗透到数值计算实践（Strassen 类算法已用于大矩阵 BLAS）。更重要的信号意义：**AI 系统开始反向攻克人类最高级的数学难题**。

> **博客**：https://scottaaronson.blog/?p=10379

**背景：** Scott Aaronson（量子计算顶级学者、UT Austin 教授）用这种标题发文，本身就是历史事件。结合 Reddit 传闻帖（"Rumors swirling that labs might have cracked Factoring in P"，458 分）和 **Google Cogentic 论文包的发布**，今天的理论 CS 圈处于极度亢奋状态。整数分解是"经典世界最著名的未解难题之一"——RSA 的整个安全模型建立在"大数分解无多项式算法"之上。（原文抓取失败，内容基于链接上下文，**待验证**。）

> **仓库**：https://github.com/google-research/google-research/tree/master/cogentic_research_papers

**已确认的论文列表（已核对 README 原文）：**
- **《Unconditional Integer Factorization in Time L_N[1/3, O(1)]》**（11-25）— 无条件整数分解
- **《Discrete Logarithms in Finite Fields of Fixed Characteristic in Sub-Quasi-Polynomial Time》**（11-25）— 固定特征有限域离散对数
- 《An Exact Polynomial-Time Algorithm for 1/5-Approximate Nash Equilibria in Bimatrix Games》

- 《Breaking the Square-Root Barrier for the Log-Rank Conjecture》

**这是什么：** Google 开源 "Cogentic" 系统的一批研究论文（Cogentic 是 arXiv 2609.40324 描述的自动化数学研究系统）。**同时覆盖整数分解 + 离散对数 + 纳什均衡 + Log-Rank 猜想**——AI 数学研究系统第一次成建制地产出理论突破，且全部带可验证论文。

**安全维度的直接含义：** 固定特征域离散对数亚准多项式算法 + 因数分解 L[1/3] 改进的叠加，对**小参数 RSA/DSA/DH 是实质性风险提醒**（经典攻击面正在被系统性压缩）。Reddit 传闻"Factoring in P"目前**无任何论文支撑**（待验证），但方向值得警惕。

**同日第三击：** OpenAI math 同仓库还有一篇《The polynomial Hirsch conjecture is false》（HN 113 分）——多面体图直径经典猜想的否定。**一天之内两个猜想级突破均出自 AI 辅助数学系统。**与本周 Riemann 假设 Lean 形式化浪潮形成完整闭环：**AI 产出证明 → Lean 验证 → 人类审核，数学知识的工业流水线第一次跑通全链路。**
