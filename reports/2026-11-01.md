### 主题一:Look Only When Needed(98👍,断层第一):扩散 VLM 的"按需看图"路由

**这是什么:** 扩散视觉语言模型(DVLM)每个去噪步都全量处理输入,而视觉 token 占输入的 89-97%——绝大部分解码算力花在反复处理同一张图上。本文给 LLaDA-V 的每一步做"有没有图都一样"的对照测量,发现大部分步不需要图,于是引入"证书引导的视觉路由":只在证书判定需要时才注入视觉 token,大幅裁剪计算。

**解读:** 这是"视觉 token 经济学"的代表作,与昨日 nesformer(NES CPU 编译进 Qwen 权重)、TokenEconomizer 同属一个母题:**2026 年推理成本优化的主战场从"参数量"移到"模态路由"——按需注入而不是全量携带**。给做多模态服务的团队:这类"感知门控"比量化更适合作为第一步优化,不损失部署通用性。

### 主题二:Youtu-Parsing-Omni(68👍):一个编码器、一个 Schema、全模态解析

**这是什么:** 腾讯优图的"全能解析器":文档、图像、音频、视频统一转为基于时空的结构化记录,为"会阅读、能定位、可引用证据"的 agent 提供感知层。单一编码器(从预训练 LM 初始化以强化文字阅读)统一编码所有模态,少量融合层让视频帧注意到并发音频。

**解读:** "感知层"正在成为 agent 技术栈里独立于"推理层"的商品化组件。**判断:2027 年的 agent 采购清单会分成三栏:推理引擎(LLM)、感知层(Omni parser)、记忆层(向量库+知识库)**——Youtu-Parsing-Omni 是感知层卡位的教科书打法:一个 Schema 吃所有模态,标准化一旦成立就是平台生意。给做 RAG/知识库的团队:模态统一解析能直接解决"视频/音频证据链"的老大难。

### 主题三:A-RSI(65👍):递归自我改进的"何时刷新"机制

**这是什么:** 自我改进型系统的老问题:模型怎么知道"当前经验已经失效、该换新任务了"?A-RSI 把"何时获取新经验"(由训练动力学决定)与"新任务答案是否可信"(不依赖自一致性投票)拆开处理,自适应刷新任务。
