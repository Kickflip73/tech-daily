### 1. bytedance/deer-flow — 字节开源 SuperAgent 编排框架（总 ⭐78,717）

> **仓库**：https://github.com/bytedance/deer-flow
> **语言**：Python | **总星标**：78,717 | **Forks**：10,741

**这是什么：** 字节跳动开源的 SuperAgent 编排框架，让 AI Agent 具备处理从分钟级到小时级复杂任务的能力。核心设计：用沙箱、记忆、工具、子 Agent 和消息网关来编排不同层级的任务。

**核心能力：**
- **Sub-Agents 编排**：支持多层 Agent 嵌套，复杂任务自动拆分为子任务
- **沙箱文件系统**：Docker/K8s 隔离执行环境，安全运行 AI 生成的代码
- **长期记忆**：跨会话记忆持久化，避免重复劳动
- **Skills & Tools**：可插拔技能系统，支持 MCP Server 集成
- **消息网关**：Agent 间通信的统一协议

**与昨日 deer-workflow 的关系：** deer-flow 是字节 Deer 团队的整体 SuperAgent 框架，deer-workflow 是其图编排运行时（TypeScript 实现）。两者互补：deer-flow 负责 Agent 运行时，deer-workflow 负责编排逻辑。

**后端开发者关注点：**
- 78k 星标说明社区认可度极高，是 Agent 编排领域最接近"事实标准"的开源项目
- Python 实现，与 LangGraph/LlamaIndex 生态无缝集成
- 适合需要编排多 Agent 协作的复杂业务场景

## 三、🔬 arXiv / HuggingFace Papers 精选

### 1. Is Deep Research Reliable? Misleading Knowledge Induces False Conclusions
> **arXiv**：2607.20891

**核心问题：** Deep Research Agent 在开放信息环境中，遇到表面可信但事实错误的信息时，是否能正确识别和拒绝？

**实验发现：**
- 团队构建了 MisKnow-Agent 框架，生成 5,933 个可控的误导性知识实例
- 在 DeepResearch Benchmark 任务上测试
- **核心结论：即使少量暴露于误导性知识，Deep Research Agent 也会在最终报告中采纳错误结论**
- 验证模型（搜索启用）能识别误导，但在长程研究流程中仍会被采纳 — 验证和流程级证据使用之间存在脱节

**后端开发者关注点：** 如果你的 Agent 在做深度研究/报告生成，需要同时在"模型层面"和"框架层面"部署证据验证和纠正能力，仅靠检索增强不够。

---

### 2. OmniScope: Modality-Decoupled Token Compression for Omnimodal LLMs
> **arXiv**：2607.23193 | [GitHub](https://github.com/MAC-AutoML/OmniScope)

**核心问题：** 多模态 LLM 中，现有 token 压缩方法用一个模态决定另一个模态保留什么，但音频和视频的相关性峰值往往不同步，导致关键信息丢失。

**解法：** OmniScope — 训练无关的 token 压缩框架：
- 查询作为共享语义锚点，但为音频和视频分别估计相关度
- 为每个模态分配独立的 token 预算
- 视觉 token 采用 anchor-delta 策略（保留全局上下文 + 时间变化）
- 音频 token 按秒合并，减少冗余但保持时间连续性

**效果：** 在 25% token 保留率下，3.53x 预填充加速 + 15% GPU 内存降低，平均精度仅下降 0.35 分。

**后端开发者关注点：** 多模态推理的显存和延迟优化是生产部署的关键瓶颈，OmniScope 提供了一个简单有效的解法。

---

### 3. ReToken: One Token to Improve Vision-Language Models for Visual Retrieval
> **arXiv**：2607.28627 | [GitHub](https://github.com/avaxiao/ReToken)

**核心问题：** 视觉语言模型处理长视觉上下文时，干扰项增多导致性能下降，GPU 内存无法容纳全部 token。

**解法：** 一个可学习嵌入（ReToken），作为显式检索目标，从预填充的视觉 KV Cache 中选择与查询相关的稀疏视觉 token 子集。

**效果：**
- Visual Haystacks：Qwen3VL-8B 提升 13.4 分，InternVL3.5 提升 12.4 分（>20% 相对提升）
- LVBench 长视频：零样本迁移，Qwen3VL-8B 提升 8.0 分
- 训练和推理均可在单张 H100 上完成

---

### 4. AISPA: User-Centric System Prompt Auditing for LLM Applications
> **arXiv**：2607.28617

**核心问题：** LLM 应用的系统提示词（System Prompt）可能存在安全隐患（提示注入、信息泄露、权限提升）。

**贡献：** 提出 AISPA 框架，从用户视角审计 LLM 应用的系统提示词安全性。自动发现提示词中的敏感信息泄露、权限配置错误等问题。

---

### 5. OSReward: Standardized Evaluation for Cross-Platform Computer-Use Reward Models
> **arXiv**：2607.28609

**核心问题：** Computer-Use Reward Model 缺乏跨平台标准化评估基准。

**贡献：** 提出 OSReward 框架，覆盖 Windows、macOS、Linux 三大桌面平台的标准化评估。

---

### 6. SCOPE: Supply-Chain Operations through Coupled Policies for End-to-End Coordination
> **arXiv**：2607.28488

**核心问题：** 供应链运营中，各环节的决策往往独立进行，缺乏端到端协调。

**解法：** SCOPE 框架，通过耦合策略实现供应链端到端协调。将供应链建模为多智能体系统，各环节的策略相互耦合和优化。

**后端开发者关注点：** 如果你在做供应链、物流、制造业的数字化系统，多智能体协调策略是一个值得关注的方向。
