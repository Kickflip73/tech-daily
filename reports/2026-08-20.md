### 1. yjh051108/dsh-routing-suite — DSH 路由套件（总 ⭐6,298）

> **仓库**：https://github.com/yjh051108/dsh-routing-suite
> **语言**：PowerShell + 多语言 | **协议**：MIT

**这是什么：** DeepSeek Harness（DSH）生态中热度最高的开源项目。这是一个"注入器 + 路由标准套件"——先安装运行时注入器，再安装任务感知的推理模式路由器。DSH 是类似 Claude Code 的终端 Coding Agent，而这个项目是让多个 DSH 实例协同工作的基础设施。

**技术架构：**
- **Runtime Injector**：注入到 DSH 的运行时环境，拦截和修改推理行为
- **Task-Aware Router**：根据任务类型自动选择不同的推理模式（Standard / Minimal / Custom）
- **与 DSH 生态深度绑定**：与 `xiaobright/dsh-anchored-standard`（两阶段预设）、`dsh-market/dsh-market`（插件市场）、`hairyf/deepseek-harness-desktop`（Tauri 桌面版）形成完整工具链

**后端开发者关注点：**
- DSH 生态的爆发说明"编程 Agent + 路由编排"正在成为开发者基础设施的标配
- 这类路由器的设计思路（任务感知 → 推理模式选择）在 Agent 平台中可复用
- 6.2k⭐ 的体量说明 DeepSeek Harness 已经积累了相当规模的社区

## 三、📄 arXiv/HF 重要论文

### 1. On the Fragility of Self-Improving Agents (arXiv 2608.18066)
> **来源**：https://arxiv.org/abs/2608.18066
> **作者**：Salesforce AI Research

**一句话总结：** 自改进 Agent 的可靠性被严重低估——评估噪声大、任务顺序依赖性强、环境描述不足会导致 Agent 失败。

**为什么重要：**
- 直接回应了 HN 上 Ornith-1.5 的"自我改进"主题
- 核心发现：改变随机种子就能移动 7.7 分，说明准确性指标本身就有很大噪声
- 提出六大行为维度来衡量模型在准确性之外的改进
- **对后端开发者的启示**：如果你在做 Agent 系统，评估方案必须跨多轮运行，不能依赖单次评估结果
