## 三、📄 arxiv 今日热点论文

### 1. ReflectRL: Learning from Golden Negative Trajectories via Reflective-to-Direct Reasoning（arXiv:2608.03972）

> **作者**：Jinhe Bi, Chennan Zhou, Zengjie Jin 等（新加坡国立大学）
> **链接**：https://arxiv.org/abs/2608.03972
> **GitHub**：https://github.com/bibisbar/ReflectRL

**摘要：** 在强化学习微调 LLM 时，当专家模型在难题上失败时，现有方法会丢弃这些失败轨迹作为负样本。论文提出 ReflectRL：将这些"黄金负轨迹"（Golden Negative Trajectories）转化为反思信号。先让 LLM 反思失败轨迹的错误，再通过 Reflective-to-Direct Policy Transition 将反思行为转化为直接推理能力。在 9 个基准测试、4 个 LLM 模型上均一致提升推理性能。

**后端开发者关注点：** 这是 LLM 训练方法论的创新——不浪费任何训练信号。如果你在做 LLM 微调或 Agent 训练，这种"从失败中学习"的思路值得借鉴。

### 2. Oilbird: Training-Free Speculative Decoding with Keys the Verifier Already Computes（arXiv:2608.03839）

> **作者**：Tao Jin, Phuong Minh Nguyen 等
> **链接**：https://arxiv.org/abs/2608.03839

**摘要：** 推测性解码（Speculative Decoding）通过小模型预测、大模型验证来加速推理。Oilbird 在此基础上创新：利用验证器（Verifier）在验证过程中已经计算过的 Key 向量来辅助小模型的预测，无需额外计算开销。训练无关，即插即用。

**后端开发者关注点：** 推测性解码是 LLM 推理加速的核心技术。如果你在部署 LLM 推理服务，Oilbird 提供了一种零训练成本的加速方案，值得关注其实际性能数据。

### 3. MAFIA: Query-Only Memory Attacks via Probing and Factual Injection against Audited LLM Agents（arXiv:2608.03844）

**摘要：** 提出 MAFIA 攻击框架：通过仅查询（Query-Only）的方式，利用探测和事实注入攻击已审计的 LLM Agent。攻击者不需要访问 Agent 的提示词或内部状态，仅通过观察 Agent 的输出就能推断其记忆内容并注入恶意信息。17 页，5 个实验图。

**后端开发者关注点：** 这是 Agent 安全领域的重要论文。如果你的 Agent 需要处理敏感信息（如用户数据、API 密钥），MAFIA 攻击揭示了"仅查询"场景下的安全风险——Agent 的记忆泄露可能通过输出模式被推断出来。

### 趋势 1：Agent 运行时基础设施从 Cloudflare 边缘到自托管全面覆盖

今天的最大信号是 **Cloudflare OS（445 HN 分）** 和 **Cloudflare computer（GitHub Trending 第一）** 同时爆发。这标志着 Agent 运行时基础设施正在从"中心化云"走向"边缘计算 + 自托管"的双轨模式：

**给后端开发者的启示：** Agent 部署正在"去中心化"。如果你在做 Agent 平台，需要考虑两种部署模式：
