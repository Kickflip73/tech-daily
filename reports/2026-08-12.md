### 1. addyosmani/agent-skills — AI Coding Agent 工程技能库（⭐74.3k）

> **仓库**：https://github.com/addyosmani/agent-skills
> **语言**：JavaScript/TypeScript

**这是什么：** 前端大神 Addy Osmani 维护的 AI 编码 Agent 工程技能集合。为 Claude Code、Cursor、Codex CLI 等 Agent 提供生产级工程技能（Skills），覆盖代码审查、重构、测试、部署等场景。

**技术架构：**
- **标准化 Skill 格式**：每个 Skill 是一个独立目录，包含 `README.md`（描述）+ `examples/`（使用示例）+ `schema.json`（输入输出定义）
- **Agent 平台兼容**：同时支持 Claude Code、Cursor、Codex CLI、Antigravity 等
- **覆盖领域**：代码质量、性能优化、安全审计、CI/CD、文档生成、数据库迁移等
- **社区驱动**：PR 驱动的 Skill 贡献流程，持续扩充

**后端开发者关注点：** 如果你在让 Agent 帮你写代码，这些 Skill 是开箱可用的"能力包"。特别是代码审查、安全扫描、性能分析类 Skill，直接集成到 Agent 工作流中能显著提升产出质量。

### 2. ruvnet/RuView — WiFi 空间感知与生命体征监测（Rust）

> **仓库**：https://github.com/ruvnet/RuView
> **语言**：Rust + TypeScript

**这是什么：** 将普通 WiFi 信号转化为实时空间智能和生命体征监测的开源项目——无需任何摄像头像素，纯 WiFi 信号实现空间定位、呼吸监测、姿态估计。

**核心技术：**
- **WiFi 射频信号分析**：利用 ESP32 固件捕获 WiFi 信号强度变化
- **空间智能**：实时定位、存在检测、区域划分
- **生命体征**：呼吸频率、心率监测（通过信号微振动）
- **前端可视化**：React + Home Assistant 集成
- **隐私优先**：零视频采集，纯信号分析

**本质洞察：** 这是"无感感知"（Passive Sensing）技术的开源实现。传统方案需要摄像头或可穿戴设备，RuView 证明了 WiFi 信号本身就能提供丰富的环境智能。

### 3. TencentCloud/TencentDB-Agent-Memory — 腾讯 Agent 记忆基础设施（⭐7.7k）

> **仓库**：https://github.com/TencentCloud/TencentDB-Agent-Memory
> **语言**：TypeScript

**这是什么：** 腾讯云开源的 Agent 长期记忆系统。将对话、文档和代码转化为四种可复用的记忆资产（Chat Memory、Skill、LLM-Wiki、Code-Graph），实现团队级记忆共享。

**四层渐进管道：**
- **采集层**：自动从对话、文档、代码中提取记忆
- **转化层**：将原始内容转化为结构化记忆资产
- **存储层**：向量搜索 + 本地持久化，零外部 API 依赖
- **检索层**：多模态查询（关键词 + 语义 + 代码图）

**后端开发者关注点：** Agent 记忆管理是规模化 Agent 应用的核心瓶颈。这个方案将记忆从"个人对话历史"升级为"团队知识资产"，设计和 OpenClaw 的 MEMORY.md 体系有相似之处。

> **语言**：待确认

### 5. trycua/cua — macOS 虚拟机 GPU 直通跑 LLM（⭐今日 +278）

> **仓库**：https://github.com/trycua/cua
> **语言**：待确认

**这是什么：** 在 Apple Silicon 上通过 macOS 虚拟机 + GPU 直通，加速 llama.cpp 本地 LLM 推理的教程和工具链。

**技术要点：**
- **GPU Passthrough**：将 M4 Pro/Max 的 GPU 直通给虚拟机，绕过 Apple 的 GPU 限制

- **性能提升**：相比原生 macOS 限制，推理速度提升显著

**后端开发者关注点：** Apple Silicon 是开发者的主力机，但 Apple 对 GPU 使用有严格限制。这个方案揭示了"虚拟机 + GPU 直通"作为绕过限制的技术路径。

## 五、🔍 趋势洞察与深度分析

### 趋势 1：Agent 安全攻防白热化

今天最大的信号来自两方面：

1. **HN 467 分热帖 + arXiv 论文**："Stealing Reasoning Traces from Proprietary LLM APIs"——攻击者可以从商业 LLM API 窃取推理链
2. **arXiv 多篇安全论文集中涌现**：ColluSkill（绕过 Agent Scanner）、ActBench（行为安全基准）、Governing the KV Cache（侧信道防护）

这标志着 Agent 安全已经从"理论讨论"进入"攻防实战"阶段。攻击面从传统的 prompt injection 扩展到推理链窃取、Skill 混淆、时序侧信道等。

**给后端开发者的启示**：如果你在生产环境部署 Agent 或 LLM API，需要关注：
- KV Cache 多租户隔离（arXiv:2608.09225 直接相关）
- Agent Skill 签名验证和沙箱隔离
- 推理链输出的访问控制

### 趋势 2：Mojo 1.0 发布 — AI 系统编程语言到来

Modular 发布 Mojo 1.0，Chris Lattner 的"AI 系统编程语言"终于落地。HN 263 分、117 条评论，Go 的 AI 辅助开发文章也同时 226 分。

这意味着两个方向正在碰撞：
- **Mojo**：高性能系统语言，直接编译到 GPU，面向 AI 基础设施
- **Go**：AI 辅助开发友好语言，简洁的语法更适合 Agent 生成代码

**给后端开发者的启示**：Mojo 的定位是"Python 的替代品"——如果你在写 AI 推理引擎、数据处理管道、GPU 计算，Mojo 值得关注。但对于常规后端服务，Go 的 AI 友好性可能更实用。

### 趋势 3：视频生成模型全面爆发

HuggingFace 模型趋势页几乎被 MiniMax-H3 和 LTX-2.5 刷屏。腾讯 Hunyuan3D-WorldClaw 也在 HN 75 分。

视频生成从"技术演示"走向"生产可用"：
- **MiniMax-H3**：33B 参数，ComfyUI 生态高度活跃
- **LTX-2.5**：Lightricks 最新发布
- **Hunyuan3D-WorldClaw**：腾讯的 3D 世界生成

**给后端开发者的启示**：视频生成对后端基础设施提出新要求——GPU 推理、视频编解码、大文件存储和传输。如果你的系统需要支持 AI 视频生成，需要提前规划这些能力。

### 趋势 4：Agent 记忆 → 团队级知识资产

腾讯 TencentDB-Agent-Memory 开源 + arXiv 多篇 Agent 记忆论文（Agentic Router、FailForge），说明 Agent 记忆正从"个人对话历史"升级为"团队知识资产"。

四层演进路径：
1. 个人记忆（对话历史压缩）→ 2. 工具记忆（使用经验）→ 3. 技能记忆（可复用 Skill）→ 4. 代码图记忆（结构化知识图谱）

**给后端开发者的启示**：如果你在做 Agent 平台，记忆层的设计应该支持多租户、版本控制、权限管理。TencentDB-Agent-Memory 的四层架构值得参考。
