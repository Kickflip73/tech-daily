### 1. Cloudflare 收购 Deno（HN 1,024 分，532 评论）——JS 运行时战争以并购落幕，边缘计算进入"一体化"时代

> **来源**：https://deno.com/blog/cloudflare

**发生了什么**：Deno 官宣被 Cloudflare 收购，这是今日全站头条（1,024 分）。同日 Cloudflare 还发布了自家多模态模型 Clef-Omni（全模态 + 更快的 Clef + 更便宜的 Clef-flash）——**这是 Cloudflare 的"战略发布日"**：买下第二大 JS 运行时 + 上架自有模型，基础设施公司的 AI 与运行时双线布局一次亮牌。

**信号解读**：**Deno 的结局验证了一个残酷的运行时经济学**：独立通用运行时无法靠开发者爱心存活，Bun 靠商业化、Deno 靠被收购，Node 的生态护城河比所有人想的都深。三个推论：① **Serverless JS/TS 的标准化权从社区移交到单一公司**——Workers 运行时 + Deno 团队（Deno Deploy、JSR 包管理）组合，Cloudflare 现在同时掌握"运行时 + 边缘节点 + 包注册表"，JS 生态的"Cloudflare 栈"正在成形；② **对 Node.js 的挤压是真实的**——Deno 2 的 Node 兼容层做完后，收购价值才成立，"兼容旧世界"是卖给新主人的前提；③ 对后端团队：JSR 与 npm 的关系、Deno Deploy 与 Workers 的整合路线是未来半年 JS 基建的最大变量，**新项目技术选型暂时观望、存量项目无需动作**。与本周 JPEG XL 入 Chrome 连读：**基础设施层正在加速整合，独立开源基建"既成功又无法独立生存"的悖论本周再次显形**。
