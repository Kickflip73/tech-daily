### 🔬 AI / 大模型

**arXiv:2608.21156 — Graph Engineering：LLM Agent 时代的图工程，从个体智能到系统智能**
> 主题：AI Agent | 关键词：多 Agent 系统、图工程、系统智能

提出"图工程"（Graph Engineering）作为下一代 Agent 系统的新范式。从 Prompt Engineering → Context Engineering → Harness Engineering → Loop Engineering，再到 Graph Engineering，通过构建显式的、动态的、演化的图结构来组织任务、Agent 和系统状态。

**arXiv:2608.21278 — CLEAR：连续潜在适配器路由，保持 LLM 安全对齐的同时保护实用性**
> 主题：AI 安全 | 关键词：安全对齐、LoRA、适配器路由

CLEAR 使用轻量级的隐藏状态门控，连续控制安全低秩适配器的激活强度。在 Llama-3-8B 上，将 HarmBench ASR 从 32.3% 降到 0.5%，同时保持基模型的大部分实用性。

**arXiv:2608.21315 — Prompt-Model Interaction Reaches the Fixed Points**
> 主题：LLM 理论 | 关键词：Prompt 交互、确定性、结构读取

研究发现 prompt 的效果不是 prompt 本身的属性——针对不同模型优化的 prompt 在其他模型上性能下降，排名在中性重格式化下重排。这揭示了 prompt 与模型之间的固定点交互结构。

**arXiv:2608.21325 — Move by Move：测量和引导 LLM 如何进行心理治疗**
> 主题：AI 应用 | 关键词：LLM 行为分析、心理治疗

研究者开发了十个治疗动作的分类体系，发现前沿模型过度使用询问（是人类的三倍），忽视心理教育，且强烈依赖人类治疗师发起的策略。提供分类体系作为工具可以将与人类治疗师的一致性提高 7-9 个百分点。

**arXiv:2608.21356 — AI with Authority, from Application to Silicon**
> 主题：AI 验证 | 关键词：形式化验证、AI 辅助证明

报告了生成式 AI 如何颠覆 60 年来机器验证的成本关系——在 AI 速度下，机器验证不仅经济而且对生产力至关重要。这是 AI 辅助形式化验证的里程碑。
