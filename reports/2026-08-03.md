### 1. ReToken: 一个 Token 提升视觉语言模型的视觉检索能力

> **arXiv**：2607.28627 | [GitHub](https://github.com/avaxiao/ReToken) | ⭐ 6

**核心贡献：** 长视觉上下文对 VLM 是个挑战——干扰物增多时性能下降，一次性处理所有 token 又超出 GPU 显存。ReToken 是一个单一可学习嵌入，作为显式检索目标，从预填充的视觉 KV Cache 中选择稀疏的相关 token。

**性能数据：**
- Visual Haystacks：Qwen3VL-8B 提升 13.4 分，InternVL3.5 提升 12.4 分（>20% 相对提升）
- LVBench 长视频零样本迁移：Qwen3VL-8B 提升 8.0 分
- **训练 + 长视频推理全部在单张 H100 上完成**

**后端开发者关注点：** 如果你在构建需要处理长视觉内容（视频分析、多图文档理解）的 Agent，ReToken 提供了一种轻量级的高效方案。

### 2. Revisiting Lossy Verification in Speculative Decoding — 推测性解码有损验证的系统性分析

> **arXiv**：2607.26627 | [GitHub](https://github.com/ZhouYuxuanYX/Fast-HSD) | ⭐ 2

**核心贡献：** 推测性解码（SD）通过小模型起草、大模型验证来加速推理。近期研究引入"有损验证"进一步提升效率，但会 silently 改变生成分布。本文首次对各类有损验证方法进行了系统化分类和诊断评估。

**关键发现：**
- 有损验证方法可分为两类：**截断式验证**和**协作式验证**
- 截断式方法存在根本性缺陷：分布畸变导致性能显著下降
- 协作式验证的关键原则：**控制 draft 概率对 target 概率的超调**

**后端开发者关注点：** 如果你在部署大模型推理服务并使用推测性解码加速，这篇论文帮你理解不同验证策略的 trade-off 和风险。

### 3. Harness-G: 图结构化的搜索 Agent 框架

> **arXiv**：2607.27652 | [GitHub](https://github.com/7HHHHH/Harness-G) | ⭐ 8

**核心贡献：** 当前 RL 搜索 Agent 将检索建模为自由形式的查询生成，存在"检索等价崩溃"（retrieval-equivalence collapse）问题——不同查询字符串检索到的证据集高度重叠。Harness-G 将自由查询生成重构为**有限动作选择**（证据句子/实体/回答），环境负责构建候选菜单和验证。

**性能数据：**
- 六个 QA Benchmark 上平均 F1 最高
- 1.5B 模型：比最强基线 Graph-R1 高 10.74 分
- 3B 模型：比 Graph-R1 高 3.98 分

**后端开发者关注点：** 如果你的 Agent 需要做多轮检索和推理，Harness-G 的图结构化检索框架提供了一种更可控的方案。

**核心贡献：** 计算机使用 Agent（如能够操作 GUI 的 Agent）的奖励模型缺乏标准化评测。OSReward 建立了一套跨平台（Windows/macOS/Linux）的标准化评测框架。

**后端开发者关注点：** 如果你在做 GUI Automation 或计算机使用 Agent，这是目前最系统的评测基准。

### 6. AISPA: 面向 LLM 应用的用户中心化系统提示审计

**后端开发者关注点：** 如果你的产品依赖系统提示来定义 Agent 行为，定期审计是必要的。AISPA 提供了方法论和工具。
