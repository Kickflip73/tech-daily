### 1. storytold/craft-anything — 「理解任意软件如何工作」的反向工程自动化平台（总 ⭐22.5K，日增 +2,548→22,564）

> **仓库**：https://github.com/storytold/craft-anything
> **语言**：Rust | **创建**：2026-10-31（8 天 22.5K，日均 ~2,800）

**这是什么：** "Craft Anything: understand how any software works, and craft your own." 一句话定位是**反向工程的工业自动化**——输入任意二进制/程序，产出去符号化之后的完整设计文档与可复刻实现。本周的叙事核心已从上周的 "clean-room replication pipeline"（+4,232→+3,078→+2,548 三日连跌但总量仍在攀升）转向「复刻能力即证明理解」。

**为什么持续上榜：** 这不是又一个 AI 工具，而是把「AI 逆向 → 规格提取 → clean-room 重写 → 验证等价」整条流水线产品化。上周引发的「replication narrative > autonomy」争论（11-04 报告）仍在发酵——当 agent 能在一周内复刻自己（8KB skill 复刻 REA 类目本身），「原创性」的定义正在被改写。

**后端开发者关注点：** 增长已过峰值进入平台期（+2548 < 昨日 +3069），但 8 天 22.5K 的曲线依然陡峭。值得关注的不是项目本身，而是它代表的范式：**逆向工程 + 生成式重写**可能成为遗留系统现代化（legacy migration）的标准路径——比人工重写便宜一个数量级。

### 3. KKKKhazix/agent-autoloop — 命令行 Agent 自主接单（总 ⭐4.1K，日增 +277）

> **仓库**：https://github.com/KKKKhazix/agent-autoloop
> **语言**：TypeScript | **描述**：让你的命令行 Agent 在后台自己接活、自己跟进到底；平时不烦你，遇到拿不准的事才发卡片找你拍板。

**这是什么：** 国产开源的 CLI Agent 自治循环框架。核心设计哲学是**「管理式自治」**：agent 平时静默干活，只在决策点（拿不准的事）发「卡片」请求人类拍板——本质上把传统的「人发指令 agent 执行」翻转为「agent 执行人类审批」。

**与 OpenClaw 同构：** 这个模式（后台任务 + 例外上报 + 人类只在关键节点介入）正是当前 agent runtime 的主流收敛方向。和 11-06 报道的 Claude Code 事件（identity 泄漏、1545pt）一起看：行业正在同时解决「agent 太吵」和「agent 太危险」两个极端。

**后端开发者关注点：** 如果你做内部工具的 agent 化改造，这种 exception-based 汇报模型比 constant-streaming 模型噪音低一个量级，值得直接抄。

### 📄 SLA: Scaling Spatial-Language-Action Model via Continual Pre-training（81 👍）
