## 三、📚 前沿论文速览（arXiv + HuggingFace Papers）

> **今日总主题：Agent 的"自我改进"成为论文主旋律。** arXiv 为 9/28 提交批次（50 篇），HF Daily Papers 换新一批（30 篇，赞数从零起算），缺跨日对比口径，重点看单日结构。

### 🧠 HF 榜首：视觉主干的"自我改造"时代

**1. VisionHOPE: Visual Backbones as Self-Modifying Learning Systems**（HF **107👍**，今日断层第一）
- 把视觉主干从 CNN → ViT → SSM → TTT 的演进推到下一步：**首个通用的"自修改学习系统"视觉主干**——模型在处理图像的过程中，"记什么"和"怎么学"共同演化，而不是由训练时定死的规则决定。
- 为什么重要：测试时训练（TTT）路线从"适应性层"走向"整个主干可自修改"，**推理时的计算不再只是算得更多，而是学得更多**。对端侧团队：这类方法对内存与训练管线的要求与常规推理完全不同，选型时别只看 FLOPs。

**2. Groupwise Agentic Grading and Advantage Redistribution for Code Agent RL**（HF **89👍**，今日第二）
- 代码 Agent RL 的痛点：GRPO 给所有通过测试的轨迹打相同的优势分，无法区分"干净实现"和"乱改一气但碰巧通过"。GAGAR 做质量感知的信用再分配。
- 为什么重要：**"通过测试"不再等于"做得好"——Agent RL 的奖励设计正在从二值走向质量分级**，这与人类代码评审的估值逻辑对齐。做 Agent 训练的团队值得精读。

**3. Recursive Harness Distillation across Agents for Robot Manipulation**（HF 29👍）
- 强 Agent 把干预经验蒸馏成"playbook"，轻量 Agent 执行后反馈，递归打磨——机器人操作的"经验跨 Agent 复用"。**harness（工具编排层）正式成为可训练、可蒸馏的资产。**

### ⚙️ arXiv 精选：harness 学习与 Agent 经济学

**4. Harness Learning Enables Generalizable Test-Time Adaptation**（arXiv 9/28）
- 把 Agent 定义为"模型 + harness（组织模型调用、工具使用、信息流的可执行程序）"，训练 proposer 模型用执行反馈改写 solver 的 harness——**"harness 修订 = 元学习中的权重更新"**。与 HF 侧 Recursive Harness Distillation 同日共振：**本周，"改 harness"取代了"改 prompt"，成为 Agent 适应性的主要杠杆。**

**5. TokenCast: Forecasting Token Consumption During LLM Agent Execution**（arXiv 9/28）
- 同一任务多次执行，token 消耗可差一个数量级；TokenCast 学习可组合的成本表征，在执行中滚动预测总消耗。**Agent 的"成本可观测性"第一次有了专门方法**——与今日 GPT 6.1 Sol 价格战 + Dots 常驻 Agent 连读，成本预测即将成为 Agent 平台的标准组件。

**6. Failure-Transparent Agents: Benchmarking Post-Failure Reporting**（arXiv 9/28）
