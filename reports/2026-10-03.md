## 三、📚 前沿论文速览（arXiv + HuggingFace Papers）

### 🔴 高关注度论文

**1. OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video Interaction**（HF 146👍）
- 本日 HF 最高赞：流式视频交互中统一感知、记忆与主动响应。**视频理解从"片段问答"走向"持续在场"——模型像人类一样"一直在看"，并主动开口**。这是 Agent 从文本走向视觉常驻的关键架构，与 GitHub 上 coucou/OpenDots 的"常驻 Agent"产品潮构成学术-产业双螺旋。

**2. On-Policy or Off-Policy Learning? A Systematic Study of Distillation Dynamics**（HF 114👍）
- 蒸馏动力学的系统研究：on-policy 与 off-policy 蒸馏的边界条件首次被大规模实证。**大模型知识传递的"配方表"正在被写清**——对任何做模型压缩/小型化部署的团队都是必读。与 arXiv《From Gradients to Capabilities: Understanding Multi-Teacher On-Policy Distillation》同日出现：**蒸馏从工程技巧升格为一门有理论的研究领域**。

**3. Fewer Tokens, Better Action: GPT-6 Astra Robot Agents with 14% Higher Success Rate but 65% Fewer Tokens**（HF 24👍）
- 机器人 Agent 的 token 经济学：减少 65% token 反而提升 14% 成功率。**"少说多做"在具身智能中首次被系统证明——动作表征的抽象层级是机器人 Agent 成本与性能的共同杠杆**。

**4. Keyword Harnesses Fail Open: A Cheap Diagnostic Ladder for Tool-Use Claims in Small Language Models**（HF + arXiv 双榜）
- 重要负结果：小模型的工具调用能力声称大量依赖关键词 Hack（"fail open"——表面上通过了，实际没学会）。**与昨日《Removing Timing Shortcuts》构成"基准审计双连击"：工具使用基准的可信度正在被系统性拆穿**。对所有 Agent 评测团队：这是比分数更重要的方法论论文——你的模型是真的会用工具，还是背了关键词？

**5. E-MoE: Enhanced Mixture-of-Experts for Non-Factorized Diffusion Language Models**（HF 49👍）
- 非分解扩散语言模型的 MoE 增强——**扩散 LM 的架构军备开始对齐自回归阵营的效率工具箱**。扩散 vs 自回归的路线之争进入"互抄作业"的收敛阶段。

**6. X-Tree: Tokenizing Reusable Experience for Efficient Agent Generalization**（HF 12👍）
- 把 Agent 的可复用经验 token 化以实现泛化——**"经验即 token"的框架让 Agent 的跨任务学习有了具体编码方案**。与 SkillGym（昨日）、AutoCompact（今日 arXiv）共同指向：Agent 的"学习"不再只是微调权重，而是管理经验表示。

**7. Decoding Looped Transformers Better for (Almost) Free**（HF 18👍）
- 循环 Transformer 的解码优化几乎零成本——**循环/递归架构的推理效率工程化加速**，与上周《Scaling Laws for Looped MoE》构成循环架构的"理论+工程"双线。

**8. CorrGRPO: Correlation-Normalized GRPO for Multi-Reward Learning**（HF 16👍）
- 多奖励 GRPO 的相关性归一化——**RLHF 的多目标冲突（有用/无害/准确）有了新的标准化手段**。奖励工程延续昨日 BiasReducer/Rubric Rewards 的工程化主线。

**9. PhysVista: Benchmarking Physical Intelligence in VLMs**（HF 12👍）
- 通过感知-推理-评估循环测 VLM 的物理智能——**"物理常识"正式成为 VLM 的独立评测轴**，具身智能的评估地基又厚了一层。
