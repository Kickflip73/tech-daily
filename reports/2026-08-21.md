### 趋势 4：供应链安全进入"构建时攻击"时代

HN 上 **恶意 Rust crate `arrayref`** 的讨论（374 分，353 评论）揭示了一个严峻的新威胁向量：

**信号证据：**
- 攻击者利用 Rust 的 proc macro 在编译时执行恶意代码
- 构建时攻击绕过所有运行时安全检测机制
- CI/CD 流水线成为主要攻击面

**给后端开发者的启示：**
- 立即审计你的构建依赖，特别是涉及 proc macro / annotation processor 的库
- Java 生态同样面临类似风险：Lombok、MapStruct 等编译期代码生成工具如果被污染，后果相同
- 建议在企业内部建立私有 Maven / Cargo registry，所有外部依赖需经过安全审查
- SBOM（软件物料清单）生成和依赖图谱可视化应成为 CI 的标配
