### 2. erkamyaman/rust-anything — 渐进式 Rust 重写工具（⭐9,202，今日 +499）

> **仓库**：https://github.com/erkamyaman/rust-anything
> **语言**：Rust

**这是什么：** "一次一块地把整个应用重写成 Rust"——每一步都用原始程序录制的行为做回归校验。支持 CLI、HTTP 服务、库的渐进式替换。

**技术核心：** 传统"Rewrite in Rust"是全量重写（高风险、周期长）。rust-anything 把重写变成**增量、可验证**的流水线：
1. 对原始程序行为做录制（行为快照 = 测试基线）
2. 每移植一个模块，用录制行为做差分验证
3. 逐步替换，全程保持系统可用

**同期对照组——fast-anything（⭐3,597，今日 +485）：** 同一生态位的"反鸡汤"版本："Don't rewrite it in Rust. Rewrite the 5% that's slow"（别全重写，只重写慢的 5%）。Profile Python/Node/Ruby 应用 → 定位热点函数 → 用 coding agent 移植热函数到 Rust → 差分验证行为一致。**两个项目今日同时大幅上涨，"渐进式性能优化 + AI 辅助移植"是共识方向，分歧只在于终点是 100% Rust 还是 5% Rust。**

**后端开发者关注点：** 这是"AI Agent 时代重构方法论"的具象化——行为录制作为黄金测试集 + Agent 执行机械移植 + 差分校验兜底。同样的方法论可以平移到 Java 技术栈（Java→Kotlin、单体→微服务拆分都可以套用"录制-替换-校验"三段式）。

### 5. AFK-surf/xnulinux — XNU 内核作为 Linux 可加载模块（⭐3,346，今日 +1,330）

> **仓库**：https://github.com/AFK-surf/xnulinux
> **语言**：Objective-C++ / C

**这是什么：** 把 Apple 的 XNU 内核（macOS/iOS 内核）作为**可加载内核模块**跑在 Linux 里，为 arm64 Linux 提供 "macOS personality"。也就是说：Linux 内核之上运行 XNU，向上提供 macOS 系统调用接口。

**意义：** 这与上周 Kernarium（Linux-on-iOS）、WindowsiOS（Windows 11 ARM64 on iPhone）是同一个技术叙事的延续——**"内核 personalities/寄生内核"成为 2026 年系统软件的新前沿**。跨 OS 兼容层从用户态（Wine）下沉到内核态（LKM 形式的完整内核栈），arm64 统一指令集让这一切成为可能。对做系统级开发的人，这个仓库是操作系统课的活教材。
