> **语言**：Go | **总星**：888

**后端开发者关注点：**
- 如果你在用 DeepSeek API 做编码助手，这个项目对 prefix-cache 的优化思路值得借鉴
- Go 实现意味着可以轻松部署为后台常驻服务，比 Python 方案资源占用更低

### 4. huangruiteng/loopx — 长时运行 AI Agent 团队的状态内核（今日 ⭐+847）

> **仓库**：https://github.com/huangruiteng/loopx
> **语言**：Python | **总星**：847

**这是什么：** 轻量级循环工程状态内核，解决长时运行 AI Agent 团队的核心问题：状态持久化、目标管理和任务交接。

**技术细节：**
- **Agent-Loop 无关**：兼容 Codex、Claude Code 等任意编码 Agent
- **持久化目标（Durable Goals）**：Agent 重启后自动恢复上下文和任务状态
- **配额感知自动唤醒（Quota-Aware Auto-Wake）**：智能管理 API 配额，在限额恢复后自动续跑
- **可执行待办（Executable Todos）**：将目标拆解为可逐项执行的子任务
- **证据日志（Evidence Logs）**：所有 Agent 行为留痕，支持审计和回溯
- **可验证交接（Verifiable Handoffs）**：多 Agent 协作时的标准化任务交接协议

**后端开发者关注点：** 如果你在做需要长时间运行（小时级甚至天级）的 Agent 任务（如大规模代码迁移、系统重构），loopx 提供了基础设施级别的解决方案。
