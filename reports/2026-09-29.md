### 2. Contrastive-LM/CLM — 决策模型品类的第一个正经挑战者（今日 2,277 ⭐，24h +371，6 天速冲）

> **仓库**：https://github.com/Contrastive-LM/CLM
> **语言**：Python

**这是什么：** Contrastive Language Models——**用对比学习连接"状态与动作"的 System One 模型**。CLM-8B：60M Nemotron Q&A 预训练 + 30M 合成难负例 mid-train + 1M agentic 轨迹后训练，TypeSafe 兼容 API，状态与动作嵌入解耦缓存（训练与服务双便宜）。

**成绩单（README 自述，待第三方验证）：**
- 计算机操作、游戏、工具调用任务上与 Jev 打平，**延迟最高低 9 倍**

**信号解读：** 三点值得注意：① **方法论分流**——laya 走非自回归蒸馏路线，CLM 走对比学习路线，两条技术路线在同一接口规范（TypeSafe-compatible）下正面竞争，接口标准化跑在了模型竞争前面，这在 AI 品类里极为罕见；② **"verifier 优于生成器"的定位聪明**——不正面挑战 coding 生成，而是做 Agent 输出的裁判，切入了当前 Agent 可靠性最痛的预算位；③ 一周 2,277⭐ + 官方 Discord + HF 模型托管，团队运作成熟度高，非个人玩票。**决策模型品类已完成"0→1"（laya）与"1→N"（CLM/jeff/Intern-Decision）两个阶段，比 Ollama 时代的本地 LLM 品类节奏快了一倍以上。**

### 🧠 推理效率：prefill/decode 分而治之（今日 HF 榜首）

**1. Disaggregated Quantization: Specializing LLM Prefill and Decode**（HF **45👍**，今日第一）
- 核心洞察：**prefill 吃算力（低精度算术加速提示处理）、decode 吃带宽（紧凑权重减少访存）——两个阶段的最优量化本该不同**，却一直被一刀切。分离式量化按阶段特化。
- 为什么重要：与 EAServe（arXiv，多模态 LLM 的 encode-aware 分离式 serving）同日出现——**"prefill/decode 分离"从系统层（PD 分离部署）下沉到了数值层（分阶段量化）**。推理优化的下一个大杠杆是"按阶段异构化"。对自建推理团队：这是继 KV cache 量化之后最值得 POC 的方向。

**2. RayOrch: Lineage-Controlled Multi-Grain Dataflows for Foundation-Model Data Preparation**（HF **43👍**，今日第二）
- 基础模型数据准备的谱系控制数据流编程模型：把文档/视频转结构化记录的管道扩展出"父子血缘 + 多粒度"控制。**数据工程正在获得自己的"Kubernetes 时刻"——当训练数据管线复杂到需要编排原语，就有人来造编排器。**

**3. Block Sparse Attention with Log-Linear Complexity**（HF 20👍）
- 长上下文的块稀疏注意力：把"选哪些块"的瓶颈做进 log-linear 复杂度。**今日 HF 榜单前三全部是效率论文，社区的优先级一目了然。**

### 🤖 具身 / 世界模型

**4. InternW0-Δ: World Action Model with 20K+ Hours of Open Data**（HF 17👍）
- 书生系世界动作模型：视觉动力学先验 + 动作生成联合建模，**20K+ 小时全开源数据**。世界模型军备竞赛的"数据开源"路线——与闭源路线的正面对比样本即将出现。

**5. Tactile-JEPA**（HF 10👍）：分布式触觉传感器的拓扑感知自监督表征——具身智能从"看和听"进入"摸"。**JEPA 范式正在向每个感官通道扩张**（上周视觉、本周触觉），LeCun 系方法论的"通感化"值得持续追踪。

**6. D-JEPA: A Decision-Aligned Latent World Model**（HF 新上榜）
- 精准命名了"decision-local prediction gap"：**潜空间预测得准 ≠ 潜空间距离能告诉你哪个动作会成功**。决策对齐的潜空间世界模型——与 laya/CLM 的决策模型浪潮在学术侧汇流：**"为决策而学表征"是本周从工程到学术的共同转向。**

### ⚙️ Agent 安全与工程（本周主线的延续）

**7. FragToken: Amplifying LLM Inference Costs through Noncanonical Token Generation**（arXiv，9/25）
- 新型资源耗尽攻击：诱导模型生成非规范 token 序列放大推理成本。与本周"推理经济学"主题互为攻防两面——**当 token 成本成为商业模式的核心变量，token 成本也就成了攻击面。** 对外暴露 LLM API 的团队应关注。

**8. Compact Documentation for Coding Agents: A Benchmark, an Optimizer, and Why It Does Not Transfer**（arXiv，9/25）
- 用 roundtrip 基准研究"自然语言文档能否帮 coding agent 解 issue"，结论是**收益存在但迁移性差**（为一个 agent 优化的文档换一个 agent 就失效）。给所有"给 AI 写文档"团队泼冷水：**文档优化是 per-agent 的，不存在通用最优文档。**

**9. Configuration, Not Conscience: A Large-Scale Empirical Study of LLM System Prompts**（arXiv，9/25）
- 大规模分析泄露的系统提示词：系统提示的构成反映的是工程配置而非"价值观"。与昨日 trace 篡改、AgentKernel 同属"Agent 治理实证"脉络——**模型行为治理的主战场在配置工程，不在道德叙事。**

**10. Can You Check That? The Checkability Boundary for Local LLM Network Automation**（arXiv，9/25）
- 把生产配置喂给第三方前沿 LLM = 导出敏感资产；查询本地小模型 = 能力不足。论文提出"可检查性边界"框架做分流路由。**"哪些自动化输入可以出域"应该成为每家公司的显式策略，而不是每个工程师的临场判断。**

### 🔬 其他值得留意

**11. Mars-Local Compute: Bandwidth, Latency, and 400 Million Kilometers**（arXiv，9/25）：火星本地算力的带宽/延迟论证——2030 年代载人定居提案的先导工程分析，本周航天板块最硬核的一篇。

**12. Multi-agent Scaling Across Disjunctive and Compensatory Tasks**（arXiv，9/25）：用 Steiner 结构区分"可加任务 vs 补偿任务"下的多 Agent 扩展律——**"加人有没有用"第一次有了任务结构化的答案**；与 AgentWorld 基准（HF 7👍，长程协作基准：现有基准测竞争、测短程、测个体加总，唯独没测真协作）互补。

**13. Jev in the Wild**（HF 8👍）：Jev 生态的功能/应用/数据驱动分析——品类诞生不到两周已有学术生态学论文。**决策模型正经历"工程爆发 + 学术跟进"的双通道确认。**

**14. 其他快览**：Learning to Stop without Learning to Stop（自监督置信度训练砍推理长度——与 Ember-1 的"训练压缩推理"路线呼应）、New LoRA Skills Should Read but Never Write（LoRA 合并的"只读不写"原则）、User Model Extraction via Belief Self-Distillation（LLM 对用户的隐式画像可被提取——隐私新攻击面）、Weight Pair Encoding（把 Re-Pair 压缩器放进训练循环让权重自压缩）、CLIP 嵌入空间后门的区域级黑盒防御。
