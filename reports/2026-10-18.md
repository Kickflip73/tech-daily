### 🔴 OpenCode 被黑：用户凭证泄露（697 分，120 评论）— 今日头条

> **原文**：https://twitter.com/opencode/status/2111516673953935833

开源编码 Agent CLI OpenCode 官方宣布被黑、用户凭证泄露。**这是本周 Agent 安全叙事链的收尾重锤**：周一是 Skill 生态爆发（应用层），周四是 Scion/Mononoke 与 git-ai（版本控制层），周五是 MCP 能力洗白检测论文与 Home Assistant secrets 事件（权限层），**今天是供应链本体被攻破（事故层）**。

**解读：**
1. **攻击面分析**：编码 Agent CLI 是"凭证密度"最高的终端形态——API key、git 凭证、SSH、云 token 全在本地配置里，且以高权限运行。被攻破的杠杆率远超普通开发工具
2. **与本周论文互证**：arXiv 今日《Language Is a Security Surface for Agent Guards》《What Survives Self-Evolution: Provenance Marks in Copied Agent Harnesses》——学界一周内从"权限审计"推进到"Agent guard 本身的语言层攻击面"与"harness 抄袭的溯源水印"，**Agent 安全从被动审计进入主动防御设计期**
3. **行动项（加急）**：所有 Agent CLI 的凭证应迁移到短期 token + 独立作用域；存量 ~/.config 凭证尽快轮换。本周已第三次出现同类信号，这不是建议而是必然动作

## 三、🔍 前沿论文速览（arXiv + HuggingFace Daily）

> 注：HF Daily Papers 2026-10-17 榜单在报告生成时（UTC 00:15）尚未发布，以下以 10-16 完整榜单（赞数仍在增长）+ arXiv 10-17 新提交为准。

### 主题一：Agent 的"自我演化"成为能力与安全的双面议题

- **[Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation](https://arxiv.org/abs/2610.21601)**（HF 665 赞，断层第一）— 门控在线蒸馏把 RL 引入的策略偏移迁移到基础模型，**RL 训练成果的"资产化转移"方法**
- **[Self-Evolving Agent Harness](https://arxiv.org/abs/2610.18813)**（HF 196 赞）— Agent harness 的自我演化框架
- **[What Survives Self-Evolution: Provenance Marks in Copied Agent Harnesses](https://arxiv.org/abs/2610.22393)**（cs.CR 新提交）— 正面问题：harness 被抄袭/篡改后，什么能证明血统？**给 Agent harness 埋溯源水印**
- **[Mosaic: Multi-Session Agentic RL](https://arxiv.org/abs/2610.22174)**（HF 52 赞）— 跨会话的 Agent RL 训练

**解读：** "harness"一词在本周完成了从 Anthropic 内部术语到公共学术词汇的转变。当 harness 可以自我演化（Self-Evolving）且可以被抄袭（Provenance 论文），**harness 本身成了需要版本控制、防伪与审计的"活体资产"**——与 git-ai、OpenCode 被黑构成完整闭环。

### 主题二：CUA（Computer-Use Agent）基建继续加固

- **[OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use](https://arxiv.org/abs/2610.22200)**（HF 268→315 赞，持续爬升）— CUA 全开源栈
- **[FDE-Gym: The Last Mile of AI Delivery](https://arxiv.org/abs/2610.22350)**（HF 230→282 赞）— "AI 交付最后一公里"基准
- **[MAI-Gym](https://arxiv.org/abs/2610.20939)**（HF 153 赞）— GUI Agent 评测与 RL 训练平台
- GitHub 侧 outcrawlai/scout（936⭐）同步上榜——**开源 CUA 从论文到代码库的同频共振持续第三天**

### 主题三：Agent 安全的"语言层转向"（cs.CR 今日集群）

### 趋势 1：Agent 安全的"事故周"收官——从审计到被黑只用了四天

DeepSeek-V4.1-Flash-1017 的发布姿势值得单独拆解：模型本身是 Pareto 改进（更强、更快、更短），但真正的产品创新在**包装层**——
